# Heart Disease Predictor 🫀

A machine learning project to predict heart disease risk using clinical data.

## Accuracy
- Random Forest: 98.5%
- SVM: 88.7%
- Logistic Regression: 79.5%

## Dataset
Cleveland Heart Disease Dataset - 1025 patients, 13 features

## How to Run
python src/preprocess.py
python src/train.py
python src/predict.py

## Tech Stack
- Python
- Scikit-learn
- Pandas
- NumPy
